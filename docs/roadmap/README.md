# Aryntra Avni — Roadmap

## Milestone Overview
```text
V0   — Voice Foundation (Current)
V0.5 — Voice Identity Baseline & Configuration
V1   — Composite Voice Identity (Multi-source)
V1.5 — Dynamic Composition & Contextual Blending
V2   — Expressive Identity
V3   — Adaptive Identity
V4+  — Multimodal Synthetic Identity

### V0 — Voice Foundation (Current Scope)
```text
Establish consumer boundary & contract (S1)
Isolate TTS execution behind adapter interface (S2)
Provide baseline identity representation (S3)
Enable clean NAV integration (S4)
Verify quality, latency, and reliability (S5)
```

### Explicit Non-Goals for V0
```text
No composite voice blending (Human A + Human B -> Avni)
No dynamic context interpolation (70% A + 30% B)
No custom speaker embedding research
No premature distributed architecture (microservices, brokers, K8s)
No multimodal or behavioral identity modeling
```
